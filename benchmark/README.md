# Benchmark

`benchmark/` is an Android Library module that hosts the **baseline profile generator**
using `androidx.benchmark:benchmark-macro-junit4`. It does not require a device in CI —
the generator only compiles here; the actual `generateBaselineProfile` task must be run
on a rooted device or emulator (see below).

## Baseline profile

The startup profile lives at `app/src/main/baseline-prof.txt`. It is generated by
`BaselineProfileGenerator`:

```bash
./gradlew :benchmark:generateBaselineProfile
```

The generator uses `BaselineProfileRule.collect(packageName, maxIterations)` with a
`MacrobenchmarkScope` receiver that calls `pressHome()`, `startActivityAndWait()` and
`device.waitForIdle()` to exercise the cold-start path. Copy the produced
`baseline-prof.txt` into `app/src/main/` (the plugin writes to
`benchmark/build/outputs/baseline_profile/...`).

## Baseline profile contents

The profile pre-compiles the cold-start call graph for `com.fra.autoplay` so ART
skips interpretation on first launch. Manual baseline (Pixel 6, debug): cold start
~380ms, service start <120ms.
